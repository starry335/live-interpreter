Live Interpreter 0.4.3（2026-11-24）
====================================

本版是“质量档 + 稳定档”双引擎：

- 质量档（推荐，需要 Workspace ID）：Qwen3.1 流式 ASR + qwen3.8-max，
  500 ms 断句，约 2.8 元/小时；首字中位约 0.9 s，热词召回约 78%。
- 稳定档（没有 Workspace ID 时默认）：Paraformer + qwen3.8-max，500 ms，
  约 3.2 元/小时；首字约 1.9 s，热词召回约 56%。
- 省钱档（可选）：翻译模型选 qwen-mt-flash，约 0.33 元/小时；质量略低，
  首字更快。

首次启动
--------
1. 填“阿里云 API Key”（百炼，北京）。
2. 要用质量档，填“Workspace ID”（百炼控制台右上角 → 业务空间 ID）。
   不填则自动走稳定档 Paraformer；3.1 不填 Workspace 会走公共域名，长连接更容易被重置。
3. 引擎选“Qwen3.1 流式识别”，断句保持 500 ms；翻译模型默认 qwen3.8-max。
4. 内置热词默认启用：梦限大 5 人、MyGO/Mujica/Ave Mujica/梦限大/MewType、薇欧拉，
   MyGO/Mujica 10 名成员，以及家庭称呼（パパまち/ママまち/弟まち/ぽんちゃん、
   パパの/ママの/パパノ/ママノ）的 ASR 提示。不需要另选词表文件。

本版改动
--------
- 500 ms 断句：比 400 ms 少约 5 个点的碎句，端到端可懂度与 400 ms 持平（独立 judge +0.39~+0.41）。
- 显示层合并修复：短句不会再一行一个“律。”，会并成一段。
- 热词策略：裸 `りつ` 不再进入 ASR 词表（避免“振り付け→律”），`ゆの` 保留；
  裸短名必须独立成词（前后是助词/敬称/标点），不会把 `振り付け`/`ありつ` 当名字。
- qwen-mt-flash 接入：便宜约 10 倍，质量略低；在“翻译模型”下拉框选择即可。
- WebSocket ping + TCP keepalive；断线时记录 close code。

已知问题
--------
- 歌声/音乐段仍会碎，ASR 会把歌词切成短句；这不是热词问题，建议音乐段降低期望。
- 30 分钟 headless soak 0 掉线；仍建议你用自己的真实 GUI 跑一次 30–60 分钟。
- 严格对 gold 的名字精确率低于基线（人工译文常省略名字），以“可懂度 + 热词召回 + 虚警/h”为准。

安装/运行
--------
- 不要覆盖正在运行的目录；先退出旧版，再解压到新目录运行 `LiveInterpreter.exe`。
- 配置保存在 %LOCALAPPDATA%\LiveInterpreter\settings.json；本包不含 API Key / Workspace ID。
